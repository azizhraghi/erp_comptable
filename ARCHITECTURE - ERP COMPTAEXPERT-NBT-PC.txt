        │     └── Retour { achats, personnel, ..., ca, treso, ... }
        └── Mise à jour DOM des 12 cartes KPI

────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
DASHBOARD — 5. FLUX DE DONNEES DETAILLE
────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
calculateDashboard(exId)
  │
  ├── 1. Filtrer state.ecritures par exerciseId === exId
  │
  ├── 2. Parcourir chaque écriture, catégoriser par préfixe compte :
  │       60x → achats
  │       64x → personnel
  │       61x/62x → servExt
  │       66x → impots
  │       70x → ca
  │       5xx → treso/clients/fourn/stock/emprunt
  │
  ├── 3. Si pas d'écritures → fallback mockData généré
  │
  ├── 4. Calculer totalCharges = achats + personnel + impots + servExt + autres
  │
  ├── 5. Calculer resultat = ca - totalCharges
  │
  └── 6. Retourner tous les agrégats + données mensuelles

TIERS — 4. ARBRE D'APPELS DES FONCTIONS

showPage('tiers')
  └── renderTiers()
        ├── Filtrer state.tiers selon tierFilter + tierStatus + recherche
        ├── Pour chaque tier :
        │     ├── isTierMvt(tier, exId)     → mouvementé N ?
        │     │     └── getTierComptesAssocies(compteCollectif)
        │     │           └── state.pce.filter(num.startsWith(prefix))
        │     └── isTierMvt(tier, exPrevId) → mouvementé N-1 ?
        └── Render HTML cartes + dot + badge + indicateur mvt

selectTier(id)
  ├── Remplir formulaire fiche détail (tous les champs)
  ├── renderTierAssociatedAccounts(compteCollectif)
  └── Vérifier mouvement pour activer/désactiver bouton Supprimer

openTierModal(id)            [nouveau tiers]
  ├── Réinitialiser formulaire
  └── onTierNatureChange()   → pré-remplir compte collectif par défaut

saveTier()
  ├── Validation : code obligatoire, intitulé obligatoire, pas de doublon
  ├── Compte collectif doit exister dans state.pce
  ├── state.tiers.push (création) ou Object.assign (modification)
  ├── addAuditLog()
  ├── saveToStorage()
  └── renderTiers() + selectTier(editingTierId)

deleteTier()
  ├── Vérifier mouvement N (bloquant si écritures liées)
  ├── confirm() utilisateur
  ├── state.tiers.filter()
  ├── addAuditLog()
  ├── saveToStorage()
  └── cancelTierEdit()

openTierPceSearch()
  ├── Filtrer state.pce par nature (client → 411000, etc.)
  └── Modal générique avec recherche temps réel

exportTiersExcel()
  ├── state.tiers → JSON → XLSX.utils.json_to_sheet()
  └── XLSX.writeFile()

importTiersExcel()
  ├── File input → XLSX.read() → sheet_to_json()
  └── Pour chaque ligne : créer tier si code unique

TIERS — 5. FLUX DE DONNEES DETAILLE
────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
getTierComptesAssocies(compteCollectif)
  │
  ├── 1. Extraire préfixe 3 premiers chiffres de compteCollectif
  │         Ex: "411000" → "411"
  │
  ├── 2. Filtrer state.pce
  │         Condition : num.startsWith(prefix) && gestion_tiers == true
  │
  └── 3. Retourner string[] des numéros de comptes

isTierMvt(tier, exId)
  │
  ├── 1. Construire liste des comptes = [tier.compte_collectif, ...comptes_associés]
  │
  ├── 2. Vérifier state.ecritures
  │         Condition : compte ∈ liste && exerciseId === exId
  │
  └── 3. Retourner boolean

onTierNatureChange()
  │
  ├── 1. Lire la nature sélectionnée (client|fournisseur|salarie|autre)
  │
  ├── 2. Mapping automatique compte collectif par défaut :
  │        client      → 411000
  │        fournisseur → 401000
  │        salarie     → 425000
  │        autre       → (vide)
  │
  └── 3. renderTierAssociatedAccounts() si compte trouvé
